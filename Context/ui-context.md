# UI Theme Context

## Visual Vibe & Aesthetics
CareerForge operates as a dark, premium, technical workbench. The interface targets high density, absolute precision, and zero friction, omitting light modes entirely. Layout blocks use precise wire framing borders and clean absolute tracking frames to mimic a high-end IDE or development terminal.

## Token Palette (CSS Variable Targets)
- `--background`: Deep dark carbon absolute background (`#08080C`)
- `--surface-card`: Matte steel container background (`#12121A`)
- `--border-faint`: Thin wire borders and layout dividers (`#1E1E2A`)
- `--text-bright`: High contrast bright silver text (`#F1F1F4`)
- `--text-muted`: Dim professional gray technical details (`#7E7E8C`)
- `--accent-forge`: Core interactive primary triggers (Amber Forge: `#F59E0B`)
- `--accent-success`: Optimization success flags and tracking states (`#10B981`)

## Typography & Components
- **Font Face:** Monospace variables or clean technical sans-serif typography targets.
- **Border Radii:** Sharp, low-radius geometric block settings (`4px` - `6px`) to reinforce the professional engineering feel.
- **Status Badges:** Text layouts are paired with small inline indicator badges showing current application and artifact optimization scores dynamically.
